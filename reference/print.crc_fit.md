# Print a Capture-Recapture Model Fit

Displays a concise description of a model fitted by
[`crc_fit()`](https://ojalab.ue.poznan.pl/misclassCRC/reference/crc_fit.md),
including its main components and convergence status.

## Usage

``` r
# S3 method for class 'crc_fit'
print(x, ...)
```

## Arguments

- x:

  An object of class `"crc_fit"`.

- ...:

  Additional arguments. Currently unused.

## Value

`x`, invisibly.
