# Summarize Capture-Recapture Predictions

Summarize Capture-Recapture Predictions

## Usage

``` r
# S3 method for class 'crc_pred'
summary(object, ...)
```

## Arguments

- object:

  An object of class `"crc_pred"`, as returned by
  [`predict.crc_fit()`](https://ojalab.ue.poznan.pl/misclassCRC/reference/predict.crc_fit.md).

- ...:

  Additional arguments. Currently unused.

## Value

An object of class `"summary.crc_pred"`.
