# Print a Summary of Capture-Recapture Predictions

Print a Summary of Capture-Recapture Predictions

## Usage

``` r
# S3 method for class 'summary.crc_pred'
print(x, digits = max(3L, getOption("digits") - 3L), ...)
```

## Arguments

- x:

  An object of class `"summary.crc_pred"`, as returned by
  [`summary.crc_pred()`](https://ojalab.ue.poznan.pl/misclassCRC/reference/summary.crc_pred.md).

- digits:

  The number of significant digits to display.

- ...:

  Additional arguments. Currently unused.

## Value

`x`, invisibly.
